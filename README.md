# Языковой процессор: Анализатор функции print() для Python

Учебный проект по дисциплине **«Методы трансляции и верификации»**.

## Описание проекта
Кроссплатформенный графический текстовый редактор и языковой процессор, разработанный на Python с использованием стандартной библиотеки (`tkinter`). Приложение предназначено для создания, редактирования и синтаксического анализа исходного кода на языке Python (с акцентом на проверку корректности вызовов функции `print()`).

Программа работает как в операционных системах семейства **Linux** (включая Kali Linux), так и в **Windows** **без необходимости установки каких-либо сторонних библиотек или зависимостей**.

---

## Основные возможности

1. **Текстовый редактор**:
   - Поддержка работы с несколькими файлами во вкладках.
   - Нумерация строк и подсветка синтаксиса.
   - Корректная обработка табуляции (4 пробела) и горячих клавиш (включая дублирование строки `Ctrl + D`).
   - Поддержка перетаскивания файлов в окно редактора (`Drag & Drop`).

2. **Главное меню и Панель инструментов**:
   - Полностью реализованные разделы **«Файл»** (Создать, Открыть, Сохранить, Сохранить как, Выход) и **«Правка»** (Отменить, Повторить, Вырезать, Копировать, Вставить, Выделить все).
   - Раздел **«Текст»** с теоретической информацией (постановка задачи, грамматика, классификация по Хомскому, метод анализа, тестовые примеры и список литературы).
   - Справочная система и информация о программе.

3. **Синтаксический анализатор («Пуск»)**:
   - Проверка синтаксиса вызовов функции `print(...)` (контроль баланса круглых скобок и текстовых констант).
   - Вывод найденных ошибок в виде структурированной **таблицы** (с указанием пути к файлу, строки, столбца и описания ошибки).
   - **Интерактивный переход**: при двойном клике на любую ошибку в таблице курсор в редакторе автоматически перемещается на проблемную позицию.
